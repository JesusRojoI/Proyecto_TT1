Proyecto TT1 · Analizador sintáctico

Árboles de sintaxis del álgebra relacional

Colección de árboles generados por el analizador del proyecto, uno por cada operador y construcción de la gramática. Cada imagen es independiente e incluye la expresión de origen, la producción aplicada y el árbol resultante.

Haz clic en cualquier imagen para abrirla en tamaño completo. También puedes descargar la versión vectorial (SVG) de cada árbol.

01-seleccion-simple

Selección (σ) con comparador

σ(edad > 5)(Estudiantes)

El nodo σ filtra las tuplas de la relación que cumplen la condición.

relation ::= SELECT LPAREN expr COMMA relation RPAREN

PNG SVG
02-seleccion-compuesta

Selección (σ) con conjunción

σ(edad >= 18 && carrera == "ISC")(Estudiantes)

La condición combina dos comparaciones mediante el operador lógico &&.

relation ::= SELECT LPAREN expr RPAREN LPAREN relation RPAREN

PNG SVG
03-proyeccion-atributos

Proyección (π) de atributos

π(nombre, edad)(Estudiantes)

El nodo π conserva únicamente los atributos indicados en la lista.

relation ::= PROJECT LPAREN attrList RPAREN LPAREN relation RPAREN

PNG SVG
04-proyeccion-expresion

Proyección (π) con expresión aritmética

π(nombre, salario * 1.1)(Empleados)

La lista de proyección admite expresiones escalares, no solo atributos.

relation ::= PROJECT LPAREN attrList RPAREN LPAREN relation RPAREN

PNG SVG
05-join-natural

Reunión natural (⋈)

Estudiantes ⋈ Inscripciones

Sin condición explícita, la reunión se resuelve por los atributos comunes.

relation ::= relation JOIN relation

PNG SVG
06-join-theta

Reunión theta (⋈ con condición)

JOIN(Estudiantes, Inscripciones, Estudiantes.matricula == Inscripciones.matricula)

La reunión theta incorpora una condición de comparación entre relaciones.

relation ::= JOIN LPAREN relation COMMA relation COMMA expr RPAREN

PNG SVG
07-union

Unión (∪)

UNION(Estudiantes2023, Estudiantes2024)

Combina las tuplas de ambas relaciones eliminando duplicados.

relation ::= UNION LPAREN relation COMMA relation RPAREN

PNG SVG
08-interseccion

Intersección (∩)

INTERSEC(Estudiantes2023, Estudiantes2024)

Conserva las tuplas presentes en las dos relaciones.

relation ::= INTERSEC LPAREN relation COMMA relation RPAREN

PNG SVG
09-diferencia

Diferencia (−)

DIF(Estudiantes2023, Estudiantes2024)

Conserva las tuplas de la primera relación que no están en la segunda.

relation ::= DIFFERENCE LPAREN relation COMMA relation RPAREN

PNG SVG
10-producto-cartesiano

Producto cartesiano (×)

Estudiantes × Carreras

Cada tupla de la izquierda se combina con todas las de la derecha.

relation ::= relation PRODUCT relation

PNG SVG
11-agrupacion

Agrupación (γ) con funciones de agregación

γ(carrera; PROM(edad), COUNT(*))(Estudiantes)

Agrupa por atributos y calcula agregados sobre cada grupo.

relation ::= GROUP LPAREN attrList SEMICOLON aggList RPAREN LPAREN relation RPAREN

PNG SVG
12-asignacion

Asignación a variable de historial (←)

@1 <- π(nombre)(Estudiantes)

El resultado se guarda en @1 para reutilizarlo en expresiones posteriores.

relation ::= VARIABLE ASSIGN relation

PNG SVG
13-variable

Variable de historial (@n)

@1

Hoja que representa una relación previamente guardada.

relation ::= VARIABLE

PNG SVG
14-tabla

Relación base (tabla)

Estudiantes

Hoja del árbol que representa una tabla de la base de datos.

relation ::= IDENTIFIER

PNG SVG
15-expresion-anidada

Expresión anidada (operadores recursivos)

π(nombre)(σ(edad >= 18)(Estudiantes ⋈ Inscripciones))

Los operadores se anidan libremente: la proyección contiene una selección y esta una reunión.

relation ::= PROJECT ... | SELECT ... | relation JOIN relation

PNG SVG
16-comparacion-mayor-igual

Comparador mayor o igual (>=)

σ(salario >= 15000)(Empleados)

Los comparadores de signo producen un nodo de comparación dentro de la condición.

expr ::= expr GE expr

PNG SVG
17-comparacion-distinto

Comparador distinto (!=)

σ(carrera != "ISC")(Estudiantes)

El operador != se traduce a <> en la sentencia SQL.

expr ::= expr NE expr

PNG SVG
18-logica-and

Conjunción lógica (∧ / &&)

σ(edad > 18 && calificacion >= 8.5)(Estudiantes)

El nodo ∧ exige que ambas comparaciones se cumplan.

expr ::= expr AND expr

PNG SVG
19-logica-or

Disyunción lógica (∨ / ||)

σ(carrera == "ISC" || carrera == "IA")(Estudiantes)

El nodo ∨ exige que al menos una comparación se cumpla.

expr ::= expr OR expr

PNG SVG
20-negacion-logica

Negación lógica (¬ / !)

σ(!(edad < 18))(Estudiantes)

El nodo ¬ invierte el valor de verdad de la condición.

expr ::= NOT expr

PNG SVG
21-aritmetica-binaria

Aritmética binaria (+, −, ×, ÷)

σ(salario * 1.16 + bono > 20000)(Empleados)

La precedencia de * sobre + determina la forma del subárbol aritmético.

expr ::= expr PLUS expr | expr MINUS expr | expr TIMES expr | expr DIVIDE expr

PNG SVG
22-potencia

Potencia (^)

σ(edad ^ 2 > 100)(Estudiantes)

La potencia es asociativa por la derecha y tiene la mayor precedencia aritmética.

expr ::= expr POWER expr

PNG SVG
23-menos-unario

Menos unario (−)

σ(-edad < -10)(Estudiantes)

El signo negativo puede aplicarse a un atributo o a un literal.

expr ::= MINUS expr %prec UMINUS

PNG SVG
24-funcion-matematica

Función matemática

σ(SQRT(calificacion) >= 3)(Estudiantes)

Las funciones matemáticas reciben una lista de argumentos escalares.

expr ::= FUNCTION LPAREN argList RPAREN

PNG SVG
25-funcion-varios-argumentos

Función con varios argumentos

π(MOD(salario, 1000))(Empleados)

La lista de argumentos se representa como una cadena de nodos con etiquetas arg n.

expr ::= FUNCTION LPAREN argList RPAREN

PNG SVG
26-agregados

Funciones de agregación

γ(departamento; SUM(salario), PROM(salario), MAX(salario), MIN(salario), COUNT(*))(Empleados)

Cada función de agregación es un nodo independiente dentro de la agrupación.

agg ::= SUM LPAREN expr RPAREN | AVG ... | MAX ... | MIN ... | COUNT LPAREN TIMES RPAREN

PNG SVG
27-literales

Literales (número, cadena, lógico, nulo)

σ(edad > 5 && activo == TRUE && nombre != NULL && ciudad == "CDMX")(Estudiantes)

Los literales son hojas del árbol y conservan su tipo.

expr ::= NUMBER | STRING | TRUE | FALSE | NULL

28-atributo-cualificado

Atributo cualificado (tabla.atributo)

σ(Estudiantes.edad > Inscripciones.edad)(JOIN(Estudiantes, Inscripciones, Estudiantes.matricula == Inscripciones.matricula))

El atributo cualificado evita ambigüedades cuando varias tablas comparten columnas.

expr ::= QUALIFIED
