Guía de instalación y ejecución

Procedimiento para clonar el proyecto, preparar el entorno y ejecutarlo localmente o dentro de una máquina virtual. La aplicación no requiere servicios en la nube ni una base de datos del sistema: utiliza el MySQL o MariaDB instalado en el equipo y las credenciales que el usuario capture en la interfaz.

Requisitos previos

Java

JDK 21 o superior. Verifica con java -version.

Maven

Apache Maven 3.9 o superior. Verifica con mvn -version.

Base de datos

MySQL 8 o MariaDB en ejecución, escuchando en el puerto 3306.

Control de versiones

Git para clonar el repositorio desde GitHub.

Navegador

Chrome, Edge o Firefox recientes. Se recomienda conexión a internet para cargar Monaco Editor y las tipografías.

Puerto libre

El puerto 8080 debe estar disponible en la máquina.

Graphviz no se instala por separado. El frontend incluye Viz.js, una compilación de Graphviz a WebAssembly que dibuja el árbol en el navegador.

1. Clonar el repositorio

Abre una terminal en el directorio donde deseas alojar el proyecto y ejecuta:

git clone https://github.com/JesusRojoI/Proyecto_TT1.git
cd Proyecto_TT1

Comprueba que estás en la rama principal y que el archivo pom.xml se encuentra en la raíz.

git status
ls -la

2. Preparar MySQL / MariaDB

Inicia el servicio de base de datos y verifica que acepte conexiones locales por TCP:

# Debian / Ubuntu / Kali
sudo systemctl start mariadb
sudo systemctl status mariadb

# Verificar el puerto 3306
ss -ltnp | grep 3306

Si deseas cargar una base de datos de prueba incluida en el repositorio:

sudo mysql < scripts/db_test_escuela.sql
# o bien, desde el cliente de MySQL:
mysql -u root -p
SOURCE scripts/db_test_escuela.sql;
Crea un usuario con contraseña o utiliza tu usuario local. La aplicación se conecta mediante TCP (localhost:3306), por lo que el usuario debe poder autenticarse desde ese host. En MariaDB reciente, root puede usar autenticación por socket; en ese caso crea un usuario dedicado: CREATE USER 'tt1'@'localhost' IDENTIFIED BY 'tu_clave'; y otorga permisos sobre tu base.

3. Compilar el proyecto

Desde la raíz del proyecto, descarga las dependencias y genera el JAR ejecutable:

mvn clean package

Este comando también ejecuta JFlex y Java CUP para generar el analizador léxico y sintáctico. Si deseas omitir las pruebas durante una compilación rápida: 

mvn clean package -DskipTests

4. Ejecutar la aplicación

Puedes iniciar el sistema de dos formas equivalentes. La primera es mediante Maven:

mvn spring-boot:run

La segunda utiliza el JAR generado:

java -jar target/tt1-algebra-relacional-0.0.1-SNAPSHOT.jar

Cuando la consola muestre Tomcat started on port 8080, abre en el navegador:

http://localhost:8080
El manual de usuario se sirve desde /api/manual. Si el archivo manual_usuario.pdf está en la raíz del proyecto, la descarga usará esa copia.

5. Conectar la base de datos desde la interfaz

  1. En la sección Conexión a MySQL local, captura host, puerto, usuario y contraseña.
  2. Presiona Conectar. El sistema mostrará las bases de datos disponibles.
  3. Selecciona una base en el desplegable. El diccionario y el autocompletado se cargarán automáticamente.
  4. Escribe una expresión, por ejemplo π(nombre, edad)(Estudiantes), y presiona Traducir y ejecutar.
  5. Usa Ver árbol sintáctico para abrir el diagrama de Graphviz y descargarlo en JPG.

6. Ejecución dentro de una máquina virtual

El procedimiento es el mismo dentro de la VM. Solo debes asegurarte de que el puerto 8080 sea accesible desde el equipo anfitrión. Tienes dos alternativas:

Redirección de puertos (recomendada)

Si usas VirtualBox, QEMU o UTM, configura una regla de reenvío:

# Ejemplo con QEMU
qemu-system-x86_64 ... -net user,hostfwd=tcp::8080-:8080

# Ejemplo con SSH hacia la VM
ssh -L 8080:localhost:8080 usuario@192.168.1.50

Después abre http://localhost:8080 en el navegador del anfitrión.

Acceso directo por red

Si la VM tiene una IP accesible, abre http://IP_DE_LA_VM:8080 y permite el puerto en el cortafuegos:

sudo ufw allow 8080/tcp
La base de datos puede permanecer escuchando solo en 127.0.0.1 dentro de la VM; la aplicación se ejecuta en la misma máquina y no necesita exponer MySQL a la red. Evita abrir el puerto 3306.

Solución de problemas frecuentes

El puerto 8080 ya está ocupado

Detén el proceso que lo usa o cambia server.port en src/main/resources/application.properties.

ss -ltnp | grep 8080
kill PID_DEL_PROCESO

No se puede conectar con MySQL

Verifica que el servicio esté activo, que el puerto sea correcto y que el usuario tenga permisos. En MariaDB, revisa la autenticación por socket descrita en el paso 2.

El editor o el diagrama no cargan

Monaco Editor se obtiene desde un CDN. Si la VM no tiene internet, el editor usa un área de texto de respaldo y el diagrama Graphviz puede no generarse. Concede acceso a la red o carga los recursos localmente.

El manual no descarga

Confirma que manual_usuario.pdf existe en la raíz del proyecto o vuelve a compilar para incluirlo en el JAR.
