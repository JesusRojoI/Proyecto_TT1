Términos y condiciones

Al utilizar este sistema aceptas las condiciones descritas en esta página. La herramienta forma parte de un Trabajo Terminal académico del Instituto Politécnico Nacional y se distribuye con fines educativos.

Objeto y alcance

El sistema de apoyo para la enseñanza del álgebra relacional permite analizar expresiones, construir su árbol sintáctico con Graphviz, traducirlas a SQL y ejecutar consultas de lectura sobre una base de datos MySQL local. Su alcance corresponde al Trabajo Terminal I; las funcionalidades de diagramas entidad-relación y modelo relacional quedan reservadas para el Trabajo Terminal II.

La herramienta es un apoyo didáctico. No sustituye la enseñanza, la revisión humana ni la validación formal de consultas en entornos de producción.

Uso académico

  • El uso permitido es académico, personal o institucional, sin fines comerciales.
  • No se autoriza su uso para actividades ilícitas, para vulnerar sistemas o para acceder a datos sin autorización.
  • El usuario debe respetar las normas de la institución y los derechos de autor de terceros.
  • La herramienta puede utilizarse en clases, laboratorios y demostraciones académicas citando su origen.

Credenciales y datos

Las credenciales de MySQL se ingresan directamente en la interfaz y se mantienen únicamente en la memoria de la sesión del servidor local. No se envían a servicios externos ni se almacenan en archivos del proyecto.

  • El usuario es responsable de la veracidad y confidencialidad de sus credenciales.
  • El sistema ejecuta únicamente consultas de lectura (SELECT) sobre la base seleccionada.
  • El usuario debe contar con autorización para consultar la base de datos que utilice.
  • No se recopilan datos personales ni se envían métricas de uso a terceros.
No utilices credenciales de producción en equipos compartidos. Cierra la conexión desde la interfaz cuando termines de trabajar.

Responsabilidad y garantías

El software se proporciona tal cual, sin garantías expresas ni implícitas de exactitud, disponibilidad o idoneidad para un fin particular. Los autores y la institución no se hacen responsables de pérdidas de datos, interrupciones, errores de traducción o daños derivados del uso de la herramienta.

  • El usuario debe respaldar su base de datos antes de realizar pruebas.
  • Las consultas generadas deben revisarse antes de utilizarse en entornos reales.
  • El equipo puede actualizar, modificar o suspender la herramienta sin previo aviso.

Propiedad intelectual

El código, la documentación y los materiales gráficos del proyecto pertenecen a sus autores y se desarrollan en el marco del Instituto Politécnico Nacional. Se permite su consulta y uso académico; cualquier reproducción, distribución o modificación debe reconocer la autoría y respetar las disposiciones institucionales.

Las bibliotecas de terceros conservan sus propias licencias: Spring Boot, JFlex, Java CUP, Monaco Editor, Tailwind CSS, Graphviz/Viz.js y Bootstrap Icons.

Privacidad

La aplicación se ejecuta en el equipo del usuario y no incorpora servicios de analítica ni rastreo. El diccionario y las consultas se procesan localmente. El único tráfico externo corresponde a la carga de tipografías, iconos y Monaco Editor desde redes de distribución de contenido, cuando hay conexión a internet.

Vigencia y contacto

Estos términos entran en vigor en la fecha de consulta y pueden actualizarse cuando el proyecto lo requiera. Para dudas académicas o técnicas, utiliza los canales de comunicación del equipo responsable del Trabajo Terminal 2027-A159 de la Escuela Superior de Cómputo.
