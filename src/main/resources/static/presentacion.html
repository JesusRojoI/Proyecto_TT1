Trabajo Terminal 2027-A159

Sistema de Apoyo para la Enseñanza del Álgebra Relacional

Herramienta web pedagógica que permite escribir consultas de álgebra relacional, observar cada etapa del análisis léxico y sintáctico, consultar el árbol de sintaxis generado con Graphviz y obtener la sentencia SQL equivalente ejecutada sobre una base de datos MySQL real.

¿Qué es esta herramienta?

Es un sistema institucional del Instituto Politécnico Nacional, desarrollado en la Escuela Superior de Cómputo, cuyo propósito es apoyar a los estudiantes en la comprensión de la traducción entre el álgebra relacional y SQL. A diferencia de otras herramientas, expone el proceso completo: tokenización, análisis sintáctico, construcción del árbol, traducción y ejecución sobre datos reales.

Funcionalidades principales

  • Editor interactivo basado en Monaco Editor, con resaltado de sintaxis, tooltips explicativos y botones para insertar operadores.
  • Conexión con MySQL local usando las credenciales del usuario, sin almacenarlas en el servidor.
  • Diccionario de datos de la base seleccionada: tablas, atributos, llaves, relaciones y vista previa de su contenido.
  • Autocompletado inteligente: al escribir un atributo, el sistema recomienda la tabla a la que pertenece; si el atributo se comparte entre tablas, muestra todas las opciones válidas. Se acepta con Tab.
  • Análisis léxico y sintáctico con JFlex y Java CUP, con catálogo de errores y posición exacta del fallo.
  • Árbol sintáctico con Graphviz en una ventana amplia, con controles de zoom, ajuste a la ventana y descarga en formato JPG.
  • Traducción automática a SQL y ejecución de la consulta sobre la base de datos seleccionada.

Arquitectura y tecnologías

Capa de presentación

HTML5, CSS3, Tailwind CSS, Monaco Editor, Viz.js (Graphviz) y JavaScript.

Capa lógica

Java 21, Spring Boot, JFlex y Java CUP. Generación de DOT para Graphviz.

Capa de datos

MySQL local del usuario mediante JDBC. Consultas de solo lectura.

Estado del proyecto

Esta es la primera versión del Trabajo Terminal I. La generación automática de diagramas entidad-relación y del modelo relacional se implementará en el Trabajo Terminal II.

  • Diagramas entidad-relación y modelo relacional (TT-2).
  • Sustitución de palabras por símbolos griegos en el análisis léxico.
  • Gestión de roles (alumno / profesor) y módulo de administración de esquemas.
