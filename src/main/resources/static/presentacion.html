Sistema de Apoyo para la Enseñanza del Álgebra Relacional

IPN · ESCOM · Trabajo Terminal 2027-A159

¿Qué es esta herramienta?

Es un sistema web pedagógico que permite a los estudiantes de bases de datos escribir consultas en Álgebra Relacional y visualizar, paso a paso, cómo se transforman en sentencias SQL equivalentes. A diferencia de otras herramientas existentes, expone el proceso completo: análisis léxico, análisis sintáctico, construcción del árbol, traducción a SQL y ejecución sobre una base de datos real.

Funcionalidades principales

  • Editor interactivo (Monaco Editor) con tooltips explicativos y botones para insertar operadores (σ, π, ∪, ∩, −, ×, ⋈, γ).
  • Conexión con el MySQL local del usuario: explora sus bases de datos y expone el diccionario de datos de cada tabla.
  • Análisis léxico y sintáctico con JFlex y Java CUP (parser LALR), con tokenización visible y catálogo de errores.
  • Visualización del árbol sintáctico y traducción automática a SQL, incluyendo operadores anidados y funciones trigonométricas.
  • Ejecución de la consulta sobre la base de datos real y vista previa del contenido de cada tabla.
  • Historial de consultas con soporte para variables reutilizables (@1, @2, ...).

Arquitectura y tecnologías

Capa de presentación

HTML5, Tailwind CSS, Monaco Editor, JavaScript

Capa lógica

Java 21, Spring Boot, JFlex, Java CUP

Capa de datos

MySQL local del usuario, JDBC

Estado del proyecto

Esta es la primera versión del Trabajo Terminal I. La generación automática de diagramas entidad-relación y del modelo relacional se implementará en el Trabajo Terminal II.

  • Diagramas entidad-relación y modelo relacional (TT-2).
  • Sustitución de palabras por símbolos griegos en el análisis léxico (códigos unicode).
  • Gestión de roles (alumno / profesor) y módulo de administración de esquemas.
